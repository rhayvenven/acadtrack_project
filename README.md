# acadtrack_project
AcadTrack is a full-stack academic performance tracker built to help students 
monitor their grades and General Weighted Average (GWA) across terms, even 
when different schools use different grading scales (e.g., 1.0–5.0 vs 1.0–4.0).

Beyond basic CRUD for subjects, grades, and terms, AcadTrack includes a Python 
analytics service that detects performance trends and flags at-risk subjects 
before it's too late to act, calculating exactly what score a student needs 
on remaining assessments to hit their target grade.

Tech stack: Node.js, Express, MySQL, Python (FastAPI), Chart.js, HTML/CSS/JS
